# Security Policy

## Reporting a vulnerability

Found a security issue — a leaked credential, an authentication flaw, a
data-exposure bug? Please report it **privately** instead of opening a public
issue.

**Email:** mz@envisioning.com

Include enough to reproduce: the affected file or flow, the steps, and the
impact. I'll acknowledge within a few days and keep you posted on the fix.

Please hold off on public disclosure until a fix has shipped. Thanks for helping
keep Septena and its users safe.
