### Full description (max 4,000 chars — 1,963 chars)

```text
Septena is a task app that thinks with you. It is built for people who want a short list and a clear day. Capture a thought in a second, sort it when you are ready, and decide what today holds before it decides for you.

THE BASICS, DONE CAREFULLY
Inbox, Today, Upcoming, and Anytime, with areas, projects, and sections to group your work. Deadlines, repeating tasks, checklists, tags, notes, timed reminders, and attachments. Your calendar events sit beside today's tasks, so you plan against the hours you actually have.

TODAY IS YOUR CALL
New and loose tasks wait in the Inbox at the top of Today. Nothing lands on your day until you put it there. Septena also learns where you usually file things and suggests the right project on your device.

AI THAT ASKS BEFORE IT ACTS
Some tasks need a moment of thinking before anyone can act on them. Open Discuss on a task and Septena asks a short question with clear options to tap. Where it can, it drafts, compares, or looks something up, then hands you the step only you can take.

YOUR AGENTS DO THE WORK. YOU DECIDE WHEN IT IS DONE.
Connect Claude or your own MCP agent and hand it a task. It works on the task and asks you there when it needs a decision. It never closes a task on its own. Finished work waits in Review until you accept it or send it back. Stop an agent on one task, or pause all agents at once. Anything an agent writes is marked, so you always see what it touched.

THE LIST THAT LETS GO
An undated task you leave alone for 14 days moves to Faded. Once a week, Septena asks you to sweep. Keep what still matters. Let go of the rest, and it moves to the Logbook.

YOURS, BUILT IN THE OPEN
The apps and the sync server are open source under the MIT License. Your tasks stay private on your device until you sign in. When you sign in, they sync across every device through Septena's private server. Export everything as JSON, Markdown, or CSV at any time, and preview a backup before importing.
```

### Data Safety answers

| Question | Answer |
|---|---|
| Does your app collect or share any of the required user data types? | **Yes** (collects data when the user signs in to sync; does **not** share data with third parties for ads/analytics) |
| Is all of the user data collected by your app encrypted in transit? | **Yes** (HTTPS/TLS to `api.septena.app`) |
| Do you provide a way for users to request that their data is deleted? | **Yes** — both in-app (`Settings → Account → Delete Account`, `DELETE /v1/account`) and via `https://septena.app/support` |

Collected data types (all **Collected: Yes**, **Shared: No**, **Optional: Yes** — app can also export/delete at any time; purpose: **App functionality** & **Account management**):

- **Personal info → Email address:** Used for email-code sign-in and account identity.
- **Personal info → User IDs:** Internal Septena account ID for syncing across devices.
- **Personal info → Name (optional):** Profile display name if the user sets one.
- **Files and docs → Files and docs (optional):** Task attachments the user explicitly adds (uploaded only when signed in on a paid plan).
- **App activity / Other user-generated content:** Tasks, areas, projects, notes, and agent conversation turns synced to `api.septena.app`.
- **Calendar (`READ_CALENDAR`):** **Not collected / Not shared.** Read locally on-device only to display today's calendar events alongside tasks; calendar events are never transmitted to Septena's servers.

### Sensitive permission justifications

- **`SCHEDULE_EXACT_ALARM`** (`android/app/src/main/AndroidManifest.xml`):
  > Septena is a personal task manager with user-configured timed reminders. Users explicitly pick a date and exact time for a task reminder, and the app requests exact-alarm permission at runtime (`ACTION_REQUEST_SCHEDULE_EXACT_ALARM`) only when a reminder is scheduled so alerts fire at the exact time the user chose.
- **`POST_NOTIFICATIONS`:** Used solely for user-scheduled task reminders and agent questions when enabled.
- **`RECEIVE_BOOT_COMPLETED`:** Re-arms the user's scheduled local task reminders after a device reboot.
- **`READ_CALENDAR`:** Optional, requested only if the user turns on Calendar Events in Settings; read locally to show upcoming events next to Today's tasks and never leaves the device.

### App Access (for Google Play reviewers)

Google Play reviewers must be able to test signed-in sync without needing a
second signed-in device. Before submitting for review:

1. Ensure email-code sign-in is enabled on `api.septena.app` (or create a
   dedicated reviewer demo account, following ADR 0055).
2. In **App content → App access**, provide instructions for signing in (either
   a test email inbox/code accessible to reviewers or a pre-seeded demo sign-in
   method), noting that the app requires no purchase to test full task
   management, reminders, widgets, and account deletion.
